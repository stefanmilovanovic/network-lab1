# network-lab1
Packet Tracer projekat koji demonstrira konfiguraciju i funkcionisanje mrežne infrastrukture, uključujući VLAN-ove, rutiranje, OSPF, DHCP i druge mrežne tehnologije. A Packet Tracer project demonstrating network infrastructure configuration and operation, including VLANs, routing, OSPF, DHCP, and other networking technologies.
