# Redundant Network Infrastructure – Cisco Packet Tracer

## Overview
This project demonstrates the design, configuration, and testing of a redundant network infrastructure using Cisco Packet Tracer. The network is designed to maintain connectivity and minimize downtime in the event of a device or link failure.

## Technologies and Features
- **Network Redundancy and Fault Tolerance** – Redundant network paths and devices to improve network availability.
- **VLANs** – Network segmentation and logical separation of departments.
- **OSPF** – Dynamic routing and route recalculation following network failures.
- **HSRP** – First-hop redundancy and gateway failover.
- **STP** – Prevention of Layer 2 switching loops while maintaining redundant links.
- **DHCP** – Automatic IP address assignment.
- **Network Troubleshooting** – Connectivity verification and failover testing.

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI

## Redundancy and High Availability
The network is designed to eliminate single points of failure by providing redundant network devices and paths. Routing and gateway redundancy mechanisms allow the network to recover from failures and maintain connectivity.

Failover scenarios can be tested by shutting down individual interfaces or devices and verifying network connectivity after the failure.

## Project Goals
- Apply practical networking concepts and Cisco IOS configuration.
- Design a resilient network architecture.
- Understand routing convergence and gateway failover.
- Test network redundancy and fault tolerance.
